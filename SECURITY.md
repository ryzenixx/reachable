# Security policy

## Supported versions

Only the latest version receives security fixes.

## Reporting a vulnerability

Please report security vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/ryzenixx/reachable/security/advisories/new). Do not open a public issue; please give us a reasonable opportunity to investigate and coordinate disclosure.

Include a description of the issue, its potential impact, steps to reproduce it, and the affected version or commit. Avoid including real credentials or personal data.

We will review the report and coordinate the fix and disclosure with you through GitHub. Once a confirmed vulnerability is fixed, we will publish a security advisory describing the issue and its resolution.

We appreciate security researchers' contributions and will credit reporters in the advisory if they wish. You may also choose to remain anonymous.
